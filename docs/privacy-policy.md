# 파이썬 첫걸음-기초문법 개인정보 처리방침

## 제1조(총칙과 데이터 처리 구조)

불암고등학교 (이하 "학교")는 고등학교 정규 교과(정보 교과 파이썬 수업)에 쓰는 학습지원 소프트웨어 "파이썬 첫걸음-기초문법"(https://wisdompython.vercel.app, 이하 "앱")을 운영하면서 「개인정보 보호법」에 따라 이 방침을 정합니다.

앱이 다루는 정보는 저장되는 곳에 따라 다음 세 가지로 나뉩니다.

1. **외부 서버에 저장되는 정보:** 학습 코드와 문제별 연습 기록은 수탁자(Upstash)의 저장소에 저장됩니다.
2. **학생 기기에만 남는 정보:** 학습 코드와 작성 중인 답안은 학생 기기의 브라우저에만 저장되며 학교 서버로 보내지 않습니다. 학생이 "코드 빼고 연습만 하기"를 누르거나 브라우저 데이터를 지우면 삭제됩니다.
3. **요청할 때만 외부로 보내는 정보:** 학생이 "AI 피드백 받기"를 누르면 답안, 실행 결과, 질문이 수탁자(OpenAI)로 전송됩니다. 이때 학습 코드와 IP 주소는 보내지 않습니다.

앱은 이름, 학번, 연락처, 사진, 목소리를 받지 않습니다. 학습 코드와 학생을 연결한 명단은 앱에 저장하지 않고 담당 교사가 교사pc에 따로 보관하며, 평가에 활용할 때 교사가 명단과 대조해 학생별 기록을 확인합니다.

## 제2조(처리하는 개인정보 항목)

| 구분 | 항목 | 수집 방법 |
| --- | --- | --- |
| 연습 기록 | 학습 코드(무작위 6글자), 문제별 제출 횟수, 처음 통과한 시도 번호, 해결 시각, 마지막 활동 시각 | 학생이 학습 코드를 입력하고 "제출하고 채점"을 누를 때 자동 생성 |
| AI 피드백 요청 | 학생이 작성한 답안, 실행 입력값과 결과, 학생이 입력한 질문 | 학생이 "AI 피드백 받기"를 누를 때 |
| 접속 정보 | IP 주소, 접속 시각, 브라우저 종류 | 앱 이용 시 자동 생성 |

## 제3조(처리 목적)

학교는 다음 목적으로만 개인정보를 처리합니다.

1. 학생의 파이썬 기초 문법 연습 기록 저장과 학습 진도 확인
2. 교사의 수업 피드백과 수행평가 등 평가 참고 자료 활용. 평가 반영 방법은 학교 학업성적관리규정과 교과 평가 계획에 따릅니다
3. 학생이 요청할 때 AI 힌트 제공
4. 과도한 요청을 막는 등 서비스의 안정적 운영

학교는 생활지도, 상담, 출결, 기숙사 관리 등 다른 목적으로는 이용하지 않습니다. 처리 목적이 바뀌면 「개인정보 보호법」 제18조에 따라 미리 알리고 필요한 경우 별도의 동의를 받습니다.

## 제4조(보유 기간과 파기)

| 항목 | 보유 기간 | 파기 방법 |
| --- | --- | --- |
| 연습 기록 | [학업성적관리규정에 따른 기간, 해당 학년도 평가 종료 후 12개월] | 교사가 앱의 선생님 화면에서 학습 코드와 기록을 삭제 |
| 교사가 내려받은 현황 파일(CSV)과 명단 | 연습 기록과 같은 기간 | 교사 PC에서 복구할 수 없게 삭제, 종이 명단은 파쇄 |
| AI 피드백 요청 내용 | 수탁자(OpenAI)가 악용 감시를 위해 최대 30일 보관 | 수탁자가 보관 기간 후 삭제 |
| 접속 정보 | Vercel 로그 보관 설정 확인| 수탁자가 보관 기간 후 삭제 |

## 제5조(제3자 제공)

학교는 개인정보를 제3자에게 제공하지 않습니다.

## 제6조(업무위탁과 국외 이전)

학교는 앱 운영을 위해 다음과 같이 처리를 위탁하며, 모두 국외로 이전됩니다. 이전 시기와 방법은 앱 이용 시 인터넷(HTTPS)을 통한 전송입니다.

| 수탁자 | 이전 국가(저장 지역) | 이전 항목 | 위탁 업무 | 보유 기간 |
| --- | --- | --- | --- | --- |
| Vercel Inc. | 미국  | 앱으로 오가는 모든 요청 (IP 포함) | 앱 호스팅과 서버 기능 실행 | 제4조 접속 정보와 같음 |
| Upstash, Inc. | 미국 (미국 동부, 워싱턴 D.C. 일대) | 연습 기록 | 연습 기록 저장 | 제4조 연습 기록과 같음 |
| OpenAI, L.L.C. | 미국 | AI 피드백 요청 내용 (학습 코드·IP 제외) | AI 힌트 생성 | 최대 30일. OpenAI는 API로 받은 내용을 모델 학습에 쓰지 않는다고 밝히고 있음 |

위탁은 아니지만, 앱 화면을 열 때 글꼴과 파이썬 실행기 파일을 받기 위해 기기의 IP 주소와 브라우저 정보가 Google Fonts(Google LLC, 미국)와 jsDelivr로 자동 전송됩니다.

국외 이전을 원하지 않으면 제7조의 방법으로 거부할 수 있습니다.

## 제7조(정보주체의 권리와 행사 방법)

1. 학생과 보호자는 언제든지 연습 기록의 열람, 정정, 삭제, 처리정지를 교무부 김지혜에 요청할 수 있습니다. 학교는 요청을 받은 날부터 10일 이내에 처리하고 결과를 알립니다.
2. 학습 코드를 넣지 않고 "코드 없이 연습만 하기"를 고르면 연습 기록이 외부 서버로 전송되지 않습니다. 이 경우 교사가 진도를 확인하거나 평가에 활용할 수 없으며, 대체 평가 방법]로 평가합니다.
3. "AI 피드백 받기"를 누르지 않으면 OpenAI로 아무것도 전송되지 않습니다. 문제 풀이, 실행, 채점은 그대로 이용할 수 있습니다.

## 제8조(만 14세 미만 아동의 개인정보)

앱의 이용 대상은 고등학교 정규 교과 수업을 듣는 학생으로 한정하며, 만 14세 미만 아동의 개인정보를 처리하지 않습니다. 근거는 다음과 같습니다.

1. 이용자는 학교가 학습 코드를 나눠 준 고등학생뿐이며, 앱에는 누구나 가입하는 기능이 없습니다.
2. 이용자가 만 14세 미만으로 확인되면 해당 학습 코드와 기록을 즉시 삭제하고, 법정대리인 동의 절차를 마련하기 전까지 학습 코드를 발급하지 않습니다.
3. AI로 보낼 때 학습 코드와 IP 주소는 빼지만, 학생이 답안 주석이나 질문에 직접 쓴 이름은 자동으로 지우지 않습니다. 이 한계 때문에 학생에게 이름, 연락처, 개인적인 사정을 쓰지 않도록 안내합니다.

## 제9조(안전성 확보 조치)

- **관리적 조치:** 선생님 화면의 접근을 담당 교사로 한정하고 비밀번호를 공유하지 않습니다. 학습 코드와 이름의 명단은 앱과 분리해 보관합니다. 보유 기간이 끝나면 제4조에 따라 파기합니다. 학생에게 학습 코드를 다른 사람에게 알려 주지 않도록 안내합니다.
- **기술적 조치:** 이름 등 식별정보를 수집하지 않고 무작위 학습 코드만 씁니다. 모든 전송은 HTTPS로 암호화합니다. API 키와 저장소 접속 정보는 앱 코드에 넣지 않고 배포 환경의 비공개 설정에만 보관합니다. 잘못된 비밀번호와 학습 코드 입력 횟수를 제한합니다.
- **물리적 조치:** 명단과 현황 파일을 보관하는 교사 PC는 비밀번호 저장된 파일에 따라 관리합니다. 외부 서버의 물리적 보안은 각 수탁자의 데이터센터 기준을 따릅니다.
